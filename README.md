# 小熊的生字森林

國小二年級上學期（康軒版）第八課〈「聰明」的小熊〉的生字與圈詞複習遊戲。

## 三個關卡

1. **找字** — 看注音挑出正確的字，干擾選項是低年級最常混淆的字（渴/喝、烏/鳥、午/牛、忘/忙、熊/能、鴉/鴨、石/右）
2. **拼圈詞** — 依注音把字塊照順序排成圈詞，附例句
3. **寫寫看** — 田字格描紅，可把底字藏起來自己默寫；支援手指與觸控筆

答錯的題目會自動收進複習輪再考一次，最多三輪。注音為直式排列，置於國字右側。

## 字詞來源

生字與圈詞取自教育部教育百科「生字詞彙表」113 學年度・二年級・國語・康軒版・第八課：
18 個習寫字、2 個認讀字、12 個圈詞。

例句與例句注音為自行編寫標註，非課本原文，使用前請自行核對。

## 使用

單一 HTML 檔，無需建置。直接開啟 `index.html` 即可。
